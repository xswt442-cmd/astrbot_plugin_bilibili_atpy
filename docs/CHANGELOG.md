# 更新日志

## [0.1.7] - 2026-10-22

- 启动时校验 `notify_umo` 的段数。少了平台前缀（`GroupMessage:xxx` 而不是
  `lg1:GroupMessage:xxx`）时 `send_message` 找不到会话，通知静默丢掉，
  以前只有一行 warning 埋在日志里
- `/atpy UMO` 的提示写清要整行复制

## [0.1.6] - 2026-10-22

- 「神秘诡异」这类的关键词换成真正的莫名其妙向：迷惑行为、不明所以、脑回路、
  精神污染、这也能播。原来那组（未解之谜、灵异、深海）搜出来是科普和怪谈盘点，
  跟「这什么玩意儿」的错位感不是一回事

## [0.1.5] - 2026-10-21

- 选片改成五类内容按日期轮转：搞笑搞怪 / 莫名其妙 / 二游 / 王者荣耀 / 无畏契约
- 播放量区间改为 10000-5000000，不再限制发布天数（`max_days_old` 填 0 表示不限）
- 默认每天一轮，五类按日期的序数取模轮换，重启补跑都不会乱序

## [0.1.4] - 2026-10-21

- 播放量下限从 500 提到 10000，不再挑没人看的废片
- 搜索条数从 30 提到 50，门槛提高后候选仍然够
- 挡掉网文与短剧推广：标题特征词 + 集数格式正则（第1-55集 / EP01）

## [0.1.3] - 2026-10-21

- 修复风控返回非 JSON 时整轮崩掉：HTTP 状态码与解析失败统一翻成接口错误
- 补简介失败不再中断整轮，退回用搜索结果的简介继续发
- 模型调用、发评论的网络异常不再冒到调度循环

## [0.1.2] - 2026-10-21

- 修复 `@机器人 /atpy 状态` 这类写法匹配不上指令，消息落进模型让它瞎编
- 指令改成指令组下的子命令，新增 `/atpy 帮助`
- 加落空兜底：不认识的子命令回一句提示，不再交给模型

## [0.1.1] - 2026-10-21

- 插件显示名改为 `atpy`，指令改为 `/atpy`

## [0.1.0] - 2026-10-21

首个版本。

- 每天在活跃时段随机跑 3-5 轮，档期在时段内分段随机，不挤在一起
- 从关键词池抽词搜索，按播放量与发布时间内过滤，从偏冷的一半里随机取
- 让模型写一句十个字以内的锐评，超长由代码截断
- 在视频评论区发 `@朋友1 @朋友2 锐评`，同一视频不重复发
- 发完在配置的 QQ 会话同步一条，附视频链接
- `recent_bili_critics` 工具，模型可在聊天里查最近发过什么
- 预览模式：只选片和写评，不发评论
